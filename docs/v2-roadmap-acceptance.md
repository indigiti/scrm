# SchoolFlow CRM v2.1–v2.4 acceptance

This document records code-level and deployment acceptance separately. A GitHub merge is not a Cloudways deployment.

- v2.1 Foundation: scoped cleanup, preserved-administrator staging reset, private backup/restore drill, security and role regression.
- v2.2 Productivity: coherent work queue, assignment and follow-up integrity, measurable SLA and mobile-friendly actions.
- v2.3 AI Quality: school-approved knowledge, unanswered-question review, offline evaluation across campus/grade/year and safe escalation.
- v2.4 Operations: provider delivery reconciliation, idempotent messaging, deployment smoke checks and load/recovery measurements.

Do not run destructive staging cleanup or automated outbound messaging without an operator-confirmed environment and backup.
